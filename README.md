# Groundwater Depletion Prediction Model
A data science project analysing and predicting groundwater depletion 
trends in Uttarakhand, India.

## Motivation
Dehradun's groundwater levels have been declining steadily due to 
rapid urbanisation and reduced natural recharge. This project aims 
to model historical trends and eventually forecast future depletion.

## Current Stage
- Exploratory data analysis with simulated trend data
- Visualisation of depth-below-ground-level over 2000-2023
- Real CGWB dataset integration in progress

## Tech Stack
- Python
- Pandas
- Matplotlib
- LSTM model (upcoming)

## Files
- `exploration.py` — initial trend analysis and visualisation
- `groundwater_trend.png` — generated depletion graph
